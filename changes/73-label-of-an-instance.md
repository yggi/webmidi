### Added
- **`PanelEditor` edits the label of one instance of a repeated group** ([#73](https://github.com/yggi/webmidi/issues/73), the label half; the colour half waits for the owner's word): a group that repeats lists its instances under *Repeat*, one row for each value the repeat gives (from the instantiated panel, so an end that is an expression is listed too), each with a label field that is its override (`MixerStrip 3` can be "Drums"); an empty field removes the override. A change is one change to the group (one step of Undo), refused in words through the editor's note where the repeat doesn't give the value or the group already keeps 64; the instance is marked in the stage (`PanelView`'s new `marked` prop, class `marked`: outlined and filled) while its row is focused. Up to 64 rows are listed; for a larger repeat, *List from* moves the window. `@yggi/webmidi/panels` gives the operations: `repeatValues`, `repeatValueOf`, `overrideProblem`, `setOverride`, and `MAX_OVERRIDES`. `instantiate` is unchanged.

### Fixed
- **`readPanel` keeps an override only for a value its repeat produces, and at most `MAX_OVERRIDES` (64) to a group** ([#73](https://github.com/yggi/webmidi/issues/73)): an override of a group that doesn't repeat, one under a key that isn't a whole number as `String` writes it (`"02"`, `"2.5"`, a word), one outside `from` … `to` where both are plain numbers (rounded as `instantiate` rounds them), and every one past the 64th (the lowest values are kept) were kept, never read by anything, so a panel read was not the panel written. They are dropped now; where an end of the repeat is an expression its values aren't known to the reader and any whole number stays. A panel file that carries such an override reads without it (the two examples are unchanged).
