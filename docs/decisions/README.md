# Decisions

One file per decision: `NNN-slug.md`, numbered in order, never renumbered. A record has a date, a status (proposed, accepted, superseded by NNN), the context, the decision and the consequences. Add one line to the decisions list in [../MEMORY.md](../MEMORY.md) as `NNN · decision · → decisions/NNN-slug.md`.

Write a record when a choice has a rationale a later reader would otherwise have to rediscover (a rejected alternative, a trade-off). Don't write one for things the code already says.
